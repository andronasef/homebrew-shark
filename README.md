# Homebrew Tap for Shark 🦈

Official Homebrew Cask tap for **Shark**, the native Mac file manager for people who live in folders.

## Installation

Install directly via Homebrew Cask:

```bash
brew install --cask andronasef/shark/shark
```

Or tap this repository first:

```bash
brew tap andronasef/shark
brew install --cask shark
```

## Upgrading

To update Shark when a new release is published:

```bash
brew upgrade --cask shark
```

## Uninstalling

```bash
brew uninstall --cask shark
```

To remove all configuration and application data:

```bash
brew uninstall --zap --cask shark
```
